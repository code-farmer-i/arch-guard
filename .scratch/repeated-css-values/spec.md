# 同一 (属性, 数值) 跨文件重复（D19）

Status: done

## 场景（对应 REQUIREMENTS.md 的 R-85）

- `padding: 12px` 在 7 个组件的样式里各写一遍、`z-index: 9999` 在 3 个文件里重复；项目还没声明刻度
  （没声明 → D12–D14 不跑，于是这批值**完全没人看**）。
- 这其实是"事实上已经定下来的口径"，只是没有名字：下次谁改都不确定要动几处，新人照抄最近的那份。

## 目标

- 同一 `(属性, 数值)` 在 **≥3 个非令牌文件**的 CSS 里出现 → **warn**（提示提取令牌 / 收敛刻度），
  在首次出现的位置报一次，消息给出文件数。
- 不声明任何参数也判（纯事实规则，像 D03）；命中给 warn，不是 error —— "该有名字"是提示，不是违规。

## 验收标准

- 判据词汇复用 `src/data/css-value-families.ts`（长度 / 层级 / 时长三族的属性），
  所以 `display: flex` 这类**枚举值重复**不会被误报成"该提取令牌"。
- 跳过：令牌 / 色板目录里的文件（那里本来就是值的家）、`var(...)` 引用、颜色值（D03 已判"同一色值只写一次"）、
  已在声明刻度白名单里的值。
- 夹具 `repeated-values`：三处 `padding: 13px` 报一次 D19；令牌文件里的重复值、`display: flex`、
  颜色值、白名单里的值都不报。
- 等级是 **L3**（跨文件唯一性，与 D03 / D05 / C03 / C06 / S17 同族，必须全量求值）—— DESIGN §5.2 的
  D19 行与 §6.8 的"全局唯一性"行同步改。
- 双 Node `pnpm check` EXIT=0。

## 边界与取舍

- **warn 而非 error**："同一个值写了三遍"不是错，是债；error 只给"确定违规"。
- **只判数值三族的属性**：`border-color`、`font-family`、`display` 这类重复是正常写法，不提示。
- **不做自动提取**：门禁不写代码（`--fix` 已判不做），只提示"这里有 N 处，该给它个名字"。
