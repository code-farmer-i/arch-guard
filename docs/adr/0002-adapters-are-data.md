# 适配器是数据，不是插件

组件库 / 数据层 / 路由 / 样式 / i18n 的差异全部落在一份**冻结的纯数据声明**里；规则声明 `requires`，适配器未声明的能力对应规则不注册。引擎从不回调适配器：无 hook、无生命周期。

三条理由：**可判定性**（适配器若能执行任意逻辑，就无法证明规则仍落 L1–L3）、**可自检与可序列化**（数据才能被 schema 校验、被报告展示、被 diff 评审、被整目录复制）、**安全**（配置不执行项目代码，不需要沙箱）。推论：用户配置只能填数据，要写逻辑就把适配器贡献进本体。

## Considered Options

- **插件式（适配器实现 `detect` / `isXxx` 回调）** —— 灵活，但适配器能力无边界，元自检（本体不得出现具体库名）失效，判定等级也失去保证。
